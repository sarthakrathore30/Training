Box-Sizing Comparison

content-box (default)

width: 250px; padding: 30px;

Total rendered width is 250px + padding + border, so this box appears wider than 250px.

box-sizing: border-box

width: 250px; padding: 30px;

Padding and border are included within 250px, so the box stays exactly that width.

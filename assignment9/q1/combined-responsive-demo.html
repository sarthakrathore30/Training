What is Responsive Design?

Responsive design means building pages that adapt gracefully to any screen size using flexible layouts, relative units, and media queries, so the experience stays great on phones, tablets, and desktops alike.

Cheat Sheet Preview

  • Flexbox for one-dimensional layouts
  • Grid for two-dimensional layouts
  • clamp() for fluid typography
  • Media queries for breakpoints

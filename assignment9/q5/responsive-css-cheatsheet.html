Responsive CSS Cheat Sheet

Filters

filter: blur(), grayscale(), sepia(), and more can transform images with pure CSS.

Media Queries

@media (max-width: 700px) { ... } lets you apply styles only at certain screen sizes.

Responsive Design

A design approach where layouts adapt fluidly to any device or screen size.

Typography

clamp(1rem, 2vw, 1.5rem) lets font sizes scale smoothly with the viewport.

Flexbox

display: flex arranges items along a single row or column with flexible sizing.

Grid

display: grid arranges items into rows and columns for two-dimensional layouts.

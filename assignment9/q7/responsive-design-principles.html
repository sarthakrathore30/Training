Core Principles of Responsive Design

Fluid Layouts

Layouts sized in relative units so they resize smoothly with the viewport.

width: 100%; max-width: 1200px;

Flexible Media

Images and videos that scale down to fit their container without overflowing.

img { max-width: 100%; height: auto; }

Breakpoints

Specific viewport widths where the layout adjusts to fit the screen better.

@media (max-width: 700px) { ... }
